# What the Universal Pokemon Randomizer ZX 4.6.1 writes into Emerald (U)
# with the Kaizo Ironmon settings, read from its source (not a run):
# `ADDR LEN LABEL`, ROM offsets. Code first, then the data tables the
# settings rewrite, then the event scripts holding static encounters.
# Sources: Gen3RomHandler.java, gen3_offsets.ini [Emerald (U)] and the
# IPS patches under pkrandom/patches/ at tag v4.6.1. See ../randomized-roms.md.

# Code. Labels must not hold a hash sign: it starts a comment.
0x0b117a 4 starter held item: movs/adds r2 immediates (setStarterHeldItems)
0x11a1e8 1 running shoes indoors: one byte of a compare (RunIndoorsTweakOffset)
0x08af84 2 run without running shoes: nop the flag check's branch (applyRunWithoutRunningShoesPatch)
0x045c70 4 Deoxys/Mew obey: movs r1, 0 twice (attemptObedienceEvolutionPatches)
0x045c86 2 Deoxys/Mew obey: cmp r0, 0 (attemptObedienceEvolutionPatches)
0x030b0c 2 intro Pokemon: cry species (randomizeIntroPokemon, IntroCryOffset)
0x031924 2 intro Pokemon: sprite species (randomizeIntroPokemon, IntroSpriteOffset)
0x161b9c 4 roamer patch: cmp and ldr r3 moved up (applyEmeraldRoamerPatch)
0x161ba2 1 roamer patch: ldr offset (applyEmeraldRoamerPatch)

0xfe0000 72 first battle: new CreateMon routine in free space (em_firstbattle.ips)
